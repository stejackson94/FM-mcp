What these buttons do

  • Upload Data: uploads one FM HTML export and switches all queries to this uploaded dataset.
  • Clear Data: removes uploaded files and switches back to the default input_data dataset.
  • List Available Columns: shows all parsed columns and which ones are usable for ranking.
  • List Clubs: returns clubs found in the currently active dataset.

How to load views in FM

  1. Click Download Required Views at the top of this page, then unzip the downloaded file.
  2. In Football Manager, go to Scouting -> Players -> Players in Range.
  3. Open the view menu next to the current view name, then choose Custom -> Import View....
  4. In the load dialog, stay on Local, set Location to the views folder, select the file, then click Load.

Use General Metrics search for Players in Range. If you are exporting from Scouted Players, use General Metrics scouted instead.

If the views folder is missing under Documents -> Sports Interactive -> Football Manager (your version), create it and place the unzipped .fmf files there.

Uploaded files are temporary and are auto-cleared periodically.
