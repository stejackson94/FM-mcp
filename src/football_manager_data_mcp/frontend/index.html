Data Helpers

Help: what these buttons do
  • Upload Data: uploads one FM HTML export and switches all queries to this uploaded dataset.
  • Clear Data: removes uploaded files and switches back to the default input_data dataset.
  • List Available Columns: shows all parsed columns and which ones are usable for ranking.
  • List Clubs: returns clubs found in the currently active dataset.

Uploaded files are temporary and are auto-cleared periodically.
